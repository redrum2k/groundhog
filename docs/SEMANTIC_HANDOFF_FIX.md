## Change

The existing real Claude investigator still examines the accepted terms and exact
source/delivery evidence. Known deterministic factual certificates remain useful,
but an unfamiliar wording is no longer itself treated as absent evidence.

When a definitive model finding lacks the narrow certificate, and mandatory byte
checks pass, the application obtains a **blind second model assessment**. The
second call receives the complete original complaint and frozen evidence packet,
not the first answer, result, score or explanation. It must account for every
clause with verbatim coverage and resolving citations. The runtime checks:

- the first and second findings agree;
- all clauses have that same definitive result;
- concatenated clause text covers the entire complaint, including qualifiers;
- each clause cites exact allowed references that resolve against frozen bytes;
- the original dispute deadline and worker lease have enough time for the call.

Missing citations, omitted clauses, disagreement, unknown clauses, invalid output,
timeouts, closed budgets and insufficient time remain held. No claim-specific
sentence or expected evaluation result was added to runtime. This extends the
existing assessment record rather than adding another verdict store or payment
engine. Old records decode with empty optional review fields.

An incomplete structured review may receive **one counted completeness repair**
when the original dispute and worker lease still have enough time. The original
response is retained. Feedback names the missing text, invalid references or
placeholder explanation, never a preferred verdict or the first investigator's
answer. Valid semantic disagreement or UNKNOWN is not retried. A failed repair
remains held; no loop, new deadline, unrecorded SDK retry or extra budget is allowed.

The accepted result is explicitly **model-provenanced**, not a mathematical proof.
Both passes use the same model and may share errors. Exact citation validation
does not prove arbitrary natural-language entailment. This is bounded development
qualification, not independent human evaluation or unrestricted reliability.

## Financial and authority boundaries

The semantic path cannot change accepted scope, source authority, price, privacy
rules or deadlines. A supported statement is not independently established provider
fault. It cannot itself authorize a correction, capture, fee or refund. The
existing worker, review, controller authorization and payment state machine remain
in control. Paid source-learning integration still requires the explicit local
qualification opt-in, registered budget window and mock adapter. Production and
the previously running demonstrations are unchanged.
