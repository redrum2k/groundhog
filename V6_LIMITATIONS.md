# V6 limits and unqualified claims

- Twelve synthetic base worlds are a bounded functional demonstration, not a representative
  enterprise sample or12 independent mechanism families. Final inputs are now known regression
  data and cannot be reused as untouched transfer after an outcome-informed change.
- The oracle was authored by an independent native model lane before candidate selection,
  checked against materialized source bytes and independent Decimal arithmetic, then frozen.
  It was not human audited. No runtime prompt/tool receives oracle files, family labels or gold.
- Only one narrowly typed procedural operation was added. The application chose to schedule
  a pre-existing evidence-acquisition capability. It did not create a verifier, acquire external
  supplier authority, change facts, invent evidence or learn unrestricted code.
- A strong fixed checklist and functioning memory already avoid all manual uploads in these
  worlds. Evolving requires2 outside its permitted scope/history; there is no demonstrated
  recurring-action or operating-cost advantage over the strongest baseline.
- Labor timing, wages, production maintenance, upstream human document-authoring cost and
  financial reconciliation burden were not measured. Null is not zero. Synthetic registration
  calls and actual staff-role upload commands are recorded separately; do not call them payroll.
- Final holds leave4 explicitly owned pending obligations per arm. Correct holds are not
  autonomous completion. Final protocol does not pretend unperformed reviewer work has no cost.
- Final compilation uses fixed explicit terms and deterministic parsing. Memory choices and
  the original proposal are actual Claude calls; the live browser also proves one real semantic
  clarification/answer. Structured reply tests do not establish unrestricted conversation ability.
- Reviewer/customer/staff roles in demonstrations are synthetic. Independent role tokens and
  bindings are enforced, but this local demo has no production customer authentication or tenant
  isolation. Do not expose it publicly. Production human approval is not established.
- All funding/capture/release is mock with Base Commerce semantics. No testnet broadcast,
  mainnet, live transfer, refund implementation, purchase, deployment or billing change occurred.
- Full provider raw JSON is preserved for proposal and functional-memory calls. Compiler
  question/term results are retained in domain/browser responses and token usage in the ledger;
  full raw provider bodies for every compiler call are not claimed. One timeout has unknown usage.
- API costs are estimated from reported tokens and verified list prices, not audited invoices.
  Failed/uncertain attempts retain conservative reservations, including one known pretransport
  failure. The reported conservative commitment is intentionally greater than known usage cost.
- PDF support remains the bounded catalog format. Correctness now checks record associations,
  exact precision and citations, but this is not a general arbitrary-document verifier.
- Revocation is prospective and does not erase accepted pins. Source changes fail closed; stale
  procedure execution is blocked and new drafts fall back to base until appropriate revalidation.
- Post-freeze UI completion did not modify backend semantics, candidate, oracle or grading.
  Frozen scientific and later delivery revisions are separately identified in the manifests.
- EXPERIENCE_REUSE_INSTANCE remains NOT_QUALIFIED. No paired second-cycle ablation was run;
  preserved experience content or one successful memory decision is not recursive improvement.
- Current procedure pointer intentionally returned to base during rollback verification. The
  successful accepted order still pins its learned version. No unattended paid task remains
  after completion; the original mission clock and aggregate ledger are not reset.
- One abandoned early browser-development order remains in human review with expired
  authorization and an ineligible queued fulfillment job. No job is running, no retry is
  scheduled, and no expiry override was attempted. Its failure is preserved outside the
  preregistered final48-cell comparison; it is not reported as successful completion.
